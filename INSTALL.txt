MINITIGER WEB – PHASE 18.4.2
GitHub / GHCR Package Page Polish

VORAUSSETZUNG
- Branch: minitiger-v12.1
- Phase 18.4.1 ist bereits eingespielt.
- Jellyfin Server / Webbasis: 12.1.
- GHCR-Package `minitiger-web` ist Public.

ZIEL
- Die öffentliche GitHub-/GHCR-Präsentation soll nicht mehr wie ein nacktes
  Jellyfin-/Docker-Paket wirken.
- GHCR bekommt eine sichtbare, verständliche Beschreibung und Lizenz.
- Das Repository bekommt eine eigene Minitiger-README mit Sidecar-Erklärung,
  Quick Start, Unraid-Hinweisen, Tags und Kompatibilität.

ÄNDERUNGEN
- README.md komplett auf Minitiger Web umgestellt.
- Dockerfile.minitiger-sidecar bekommt aussagekräftige OCI-Metadaten:
  title, description, source, url, licenses, vendor.
- GitHub Action nutzt docker/metadata-action und schreibt dieselben Metadaten
  zusätzlich als Multi-Arch-Index-Annotations. Das ist wichtig, damit GHCR die
  Beschreibung bei amd64+arm64 tatsächlich auf der Package-Seite anzeigen kann.
- Tags bleiben: latest, 12.1 und sha-...
- README-Änderungen lösen künftig ebenfalls einen Sidecar-Build aus.

INSTALLATION AUF DEM RASPBERRY PI

1) In das Repository wechseln:
   cd ~/minitiger-web

2) Patch entpacken:
   unzip -o ~/minitiger_native_phase18_4_2_github_package_polish.zip -d ~/minitiger-web

3) Prüfen:
   chmod +x VERIFY_PATCH.sh
   ./VERIFY_PATCH.sh

4) Committen und pushen:
   git add README.md Dockerfile.minitiger-sidecar \
     .github/workflows/minitiger-sidecar.yml SIDECAR_SETUP.md \
     INSTALL.txt CHANGELOG_Minitiger_Web.txt files.txt VERIFY_PATCH.sh \
     Minitiger_Gedaechtnis
   git commit -m "Polish Minitiger GitHub package page"
   git push

5) Auf GitHub warten, bis `Build Minitiger Sidecar` grün ist.

6) Danach Package-Seite neu laden:
   https://github.com/Grunttanamo/Minitiger/pkgs/container/minitiger-web

ERWARTUNG
- Unter `minitiger-web` erscheint eine Minitiger-Beschreibung.
- Source Repository ist sauber verknüpft.
- Lizenz wird als GPL-2.0-or-later angezeigt.
- Tags latest / 12.1 / sha-... bleiben vorhanden.

OPTIONAL ABER EMPFOHLEN
Damit die normale Repository-Startseite ebenfalls sofort Minitiger zeigt:
GitHub -> Repository -> Settings -> Branches -> Default branch
und `minitiger-v12.1` als Default setzen.

HINWEIS
Die GHCR Package-Seite selbst hat ein festes GitHub-Layout. Man kann dort keine
beliebigen Banner, CSS oder freie Markdown-Seiten einbauen. Die sichtbaren
Anpassungspunkte sind vor allem Description, License, Source und Tags. Für die
richtig hübsche Projektseite ist die README.md zuständig.
