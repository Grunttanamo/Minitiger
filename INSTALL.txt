MINITIGER WEB – PHASE 18.5.0
Minitiger Virtual Sync Plugin Repository

VORAUSSETZUNG
- Branch: minitiger-v12.1
- Jellyfin Server / Webbasis: 12.1
- Phase 18.4.3 ist bereits eingespielt.
- GitHub Repository ist öffentlich, damit Jellyfin das Manifest und die Release-ZIPs ohne Login laden kann.

ZIEL
- Minitiger Virtual Sync als normales Jellyfin-Plugin verteilen.
- Nutzer sollen nur einmal die Minitiger Repository-URL in Jellyfin hinzufügen und das Plugin danach aus dem Catalog installieren.
- Plugin-Releases bleiben vollständig vom langen Sidecar-Docker-Build getrennt.

INSTALLATION DES PATCHES AUF DEM RASPBERRY PI

1) Repository öffnen:
   cd ~/minitiger-web

2) Patch entpacken:
   unzip -o ~/minitiger_native_phase18_5_0_plugin_repository.zip -d ~/minitiger-web

3) Statisch prüfen:
   chmod +x VERIFY_PATCH.sh
   ./VERIFY_PATCH.sh

4) Committen und pushen:
   git add README.md PLUGIN_SETUP.md \
     plugin-repository/manifest.json \
     .github/workflows/minitiger-plugin-build.yml \
     .github/workflows/minitiger-plugin-release.yml \
     .github/scripts/update_plugin_manifest.py \
     INSTALL.txt CHANGELOG_Minitiger_Web.txt files.txt VERIFY_PATCH.sh \
     Minitiger_Gedaechtnis

   git commit -m "Add Minitiger Virtual Sync plugin repository"
   git push

NACH DEM PUSH
- In GitHub Actions sollte `Build Minitiger Virtual Sync Plugin` automatisch starten.
- Dieser Build ist viel kleiner als der Minitiger Docker Multi-Arch Build.
- Erst wenn dieser Workflow grün ist, das erste Repository-Release erstellen.

ERSTES PLUGIN-RELEASE ERSTELLEN
GitHub -> Minitiger -> Actions -> Release Minitiger Virtual Sync Plugin
-> Run workflow

Der Workflow macht automatisch:
- .NET-10-Build / Publish

- MD5-Prüfsumme für Jellyfin
- GitHub Release `plugin-v1.0.3.0`
- Eintrag in `plugin-repository/manifest.json`
- Commit + Push des aktualisierten Manifests

PLUGIN DANACH IN JELLYFIN INSTALLIEREN
Dashboard -> Plugins -> Repositories -> +

  https://raw.githubusercontent.com/Grunttanamo/Minitiger/minitiger-v12.1/plugin-repository/manifest.json

Speichern -> Plugins -> Catalog -> Minitiger Virtual Sync -> Installieren
-> Jellyfin neu starten.
