MINITIGER PHASE 18.3.7.1 – DOCKER BUILD HOTFIX

Voraussetzung: Phase 18.3.7 ist im Repo.

Dieser Hotfix ändert nur die Docker-.NET-Buildstage plus Patch-/Gedächtnisdateien.

1) Patch auf dem Raspberry Pi einspielen:

  cd ~/minitiger-web
  unzip -o ~/minitiger_native_phase18_3_7_1_dotnet10_docker_hotfix.zip -d ~/minitiger-web
  chmod +x VERIFY_PATCH.sh
  ./VERIFY_PATCH.sh

2) Hotfix nach GitHub pushen, damit der Docker-Workflow neu startet:

  git add Dockerfile.minitiger CHANGELOG_Minitiger_Web.txt INSTALL.txt files.txt VERIFY_PATCH.sh Minitiger_Gedaechtnis
  git commit -m "Fix .NET 10 Docker SDK image"
  git push

3) Danach auf GitHub:
   Repository -> Actions -> Build Minitiger Docker

Der Workflow sollte automatisch durch den Push starten.

Wichtig:
- Der bisherige Fehler `mcr.microsoft.com/dotnet/sdk:10.0-bookworm-slim: not found` ist mit diesem Patch adressiert.
- Wenn der nächste Lauf an einer anderen Stelle rot wird, die neue rote Fehlermeldung vollständig schicken; nicht blind weitere Änderungen machen.
