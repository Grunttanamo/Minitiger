INSTALLATION AUF DEM RASPBERRY PI

1) In das Repository wechseln:
   cd ~/minitiger-web

2) Patch entpacken:
   unzip -o ~/minitiger_native_phase18_4_0_jellyfin12_1_sidecar_preview.zip -d ~/minitiger-web

3) Prüfen:
   chmod +x VERIFY_PATCH.sh
   ./VERIFY_PATCH.sh

4) Git prüfen und committen:
   git status
   git add Dockerfile.minitiger-sidecar Dockerfile.minitiger-sidecar.dockerignore \
     docker/minitiger-sidecar.conf.template docker-compose.sidecar.example.yml \
     .github/workflows/minitiger-sidecar.yml SIDECAR_SETUP.md \
     INSTALL.txt CHANGELOG_Minitiger_Web.txt files.txt VERIFY_PATCH.sh \
     Minitiger_Gedaechtnis
   git commit -m "Add Minitiger Jellyfin 12.1 sidecar"

5) Pushen:
   git push

Der Push auf minitiger-v12.1 startet automatisch den Workflow:
   Build Minitiger Sidecar

  installiert; das folgt separat, damit der Sidecar keine Serverdaten verändert.
