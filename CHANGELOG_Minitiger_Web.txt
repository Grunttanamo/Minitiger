Minitiger Web – Phase 18.4.1
Sidecar Browser Entry Hotfix

BESTÄTIGTE ERKENNTNISSE AUS 18.4.0
- Sidecar-Container startet erfolgreich.
- `/minitiger-health` liefert HTTP 200.
- `/System/Info/Public` wird mit HTTP 200 an Jellyfin 12.1 weitergeleitet.
- Jellyfin Desktop Client lädt Minitiger über den Sidecar.
- Browser lädt Minitiger erfolgreich über `/web/index.html`.
- Der kurze Browser-Aufruf nur über Host:Port landete dagegen auf Jellyfins
  roter "Software Failure / Seite nicht gefunden"-Ansicht.

FIX
- `/`, `/web` und `/web/` werden explizit auf `/web/index.html` umgeleitet.
- Der lokale `/web/`-Asset-/SPA-Fallback bleibt bestehen.
- HEALTHCHECK nutzt nun `default_type text/plain` statt eines zusätzlichen
  Content-Type-Headers.

BEDIENUNG
- Compose-Host-Port ist über `MINITIGER_PORT` konfigurierbar.
- Beispiel-Default ist jetzt 8098, weil 8097 im Testsystem durch OpenMediaVault
  belegt ist. Jeder andere freie Host-Port ist möglich.

NICHT VERÄNDERT
- Minitiger UI / Trailer / Audioflags / Manga / virtuelle Bibliothekslogik.
- Jellyfin Datenbank, Accounts, Appdata, Medien und normaler :8096-Endpunkt.
