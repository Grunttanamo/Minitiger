Minitiger Web – Phase 18.5.0
Minitiger Virtual Sync Plugin Repository

BESTÄTIGTER AUSGANGSSTAND
- Jellyfin Server / Web: 12.1.
- Minitiger Sidecar funktioniert getrennt vom normalen Jellyfin.
- Desktop Client, Login, Home, Bibliotheken, Detailseiten und Playback funktionieren über den Sidecar.
- Browser funktioniert bestätigt über /web/index.html.

NEU
- Eigenes Jellyfin-Plugin-Repository für `Minitiger Virtual Sync`.
- Repository-Manifest unter `plugin-repository/manifest.json`.
- Dokumentation `PLUGIN_SETUP.md` für normale Installation über Jellyfin Dashboard -> Plugins -> Repositories.
- Separater schneller GitHub-Workflow `Build Minitiger Virtual Sync Plugin`.
- Separater manueller Release-Workflow `Release Minitiger Virtual Sync Plugin`.
- Release-Workflow baut das Plugin mit .NET 10, erzeugt ein Plugin-ZIP, berechnet den Jellyfin-Katalog-MD5,
  erstellt einen GitHub Release und aktualisiert anschließend automatisch das Manifest.
- README verweist nun direkt auf das Companion Plugin und seine Repository-URL.

WICHTIG ZUR KOMPATIBILITÄT
- Minitiger ist auf Jellyfin 12.1 getestet.
- Jellyfin 12.x verwendet weiterhin die Plugin-ABI-Linie `12.0.0.0`.
- Deshalb targetet das Plugin-Manifest absichtlich `12.0.0.0`, während der Server-Teststand 12.1 ist.
- .NET-Ziel des vorhandenen Plugins bleibt `net10.0`.

VERTEILUNG
- Plugin-only Änderungen lösen KEINEN langen Minitiger-Sidecar-Docker-Build aus.
- Erstes geplantes öffentliches Repository-Release: `1.0.3.0`.
- Nach erfolgreichem Release-Workflow kann das Plugin über den normalen Jellyfin Plugin Catalog installiert werden.

NICHT VERÄNDERT
- Minitiger UI, Playback, Trailer, Audioflags, Manga und Sidecar-Proxy.
- Jellyfin Datenbank, Accounts, Appdata oder Medien.
- Der Sidecar installiert das Plugin weiterhin nicht automatisch.
