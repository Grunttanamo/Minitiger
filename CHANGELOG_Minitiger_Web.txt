Minitiger Web – Phase 18.4.0
Jellyfin 12.1 Sidecar Preview

NEU
- Eigenständiges Dockerfile `Dockerfile.minitiger-sidecar`.
- Minitiger Web wird mit Node 24 gebaut und anschließend in einem kleinen
  nginx-Container ausgeliefert.
- Sidecar enthält keinen Jellyfin-Server und keine Jellyfin-Datenbank.
- Bestehender Jellyfin-Server wird über `JELLYFIN_URL` reverse-proxied.
- Standard: Jellyfin auf Host-Port 8096, Minitiger auf Host-Port 8097.
- `/web/` wird lokal aus Minitiger bedient; API, WebSocket, Bilder und Streams
  werden an den bestehenden Server weitergereicht.
- Docker HEALTHCHECK über `/minitiger-health`.
- Compose-Beispiel ohne Config-/Cache-/Media-Volumes.
- Unraid-Schrittfolge ergänzt.
- Neuer GitHub-Action-Workflow `Build Minitiger Sidecar` für amd64 + arm64.
- GHCR-Ziel: `ghcr.io/grunttanamo/minitiger-web` mit `latest`, `12.1` und SHA-Tag.

SICHERHEIT / DESIGN
- Stoppen oder Löschen des Sidecars verändert den bestehenden Jellyfin-Server
  nicht.
- Das Minitiger Virtual Sync Companion Plugin wird bewusst nicht automatisch
  in fremde Jellyfin-Config-Verzeichnisse kopiert.

NICHT VERÄNDERT
- Minitiger UI / Trailer / Audioflags / Manga / virtuelle Bibliothekslogik.
- Bestehendes Full-Server-Docker-Image aus Phase 18.3.7.x.
